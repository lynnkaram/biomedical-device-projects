## Project 1: ECG Data Acquisition System

Arduino-based ECG signal acquisition and processing system designed for basic biosignal monitoring and visualization.

Files included:
- `ecg_data_acquisition.ino` --> embedded code for ECG signal sampling and acquisition
- `ECG final circuit.pdf` --> analog front-end circuit schematic and signal conditioning design

Key concepts:
- ECG biosignal acquisition
- Analog signal conditioning
- Operational amplifier filtering stages
- Arduino ADC sampling
- Biomedical instrumentation
- Embedded systems programming
- Noise reduction and amplification
- Real-time physiological signal monitoring
